# Генератор химер

## Общее описание
- Мобильное приложение
- Позволяет генерировать существ по таблицам, выбирая случайных существ из списка
- Позволяет сохранять результаты генерации
- Позволяет создавать гибриды существ по правилу
- Позволяет сохранять гибриды

## Роли

### Пользователь
- Открыть приложение в браузере
- Может выбрать число существ и сгенерировать их по таблицам.
- Посмотреть статблок выбранного существа
- Пользователь может смотреть каталог доступных в таблицах существ.
- Может выбрать двух существ и один из двух вариантов слияния химер и создать новое, выбрав основное существо и донора. Он может называть гибрид.
- Посмотреть предварительный статблок гибрида.
- Зарегистрироваться / или анонимный доступ.
- Зарегистрированный пользователь может сохранить результат в личном кабинете
- Зарегистрированный пользователь может просматривать сохранённые гибриды.
- Зарегистрированный пользователь может использовать существ из сохранённых.
- Настраивать фильтры сохранённых существ.

### Администратор
- Открыть приложение в браузере
- Зарегистрироваться
- Может менять существ: Менять имена и любые параметры статблока
- Может менять состав таблиц с существами для генерации: добавлять новые поля, удалять старые.

## Базовые сущности

- **Creatures_1** — существо (id_creature, Name, Size, AC, HP, HP_formula, CR, Strength, Dexterity, Constitution, Intelligence, Wisdom, Charisma, Proficiency_bonus, id_type).
- **Creature_types_3** — тип существа (id_type, Name).
- **Languages_2** — язык (id_language, Name).
- **Languages_Creatures** — связь M:N (id_language, id_creature, Can_speak).
- **Saving_throws_10** — спасбросок (id_save, Name).
- **Saving_throws_creatures** — связь M:N (id_save, id_creature).
- **Skills_9** — навык (id_skill, Name, Related_characteristic).
- **Skills_Creatures** — связь M:N (id_skill, id_creature, Double_proficiency).
- **Speed_5** — тип скорости (id_speed, Type_speed).
- **Speed_Creatures** — связь M:N (id_speed, id_creature, Value).
- **Actions_8** — действие (id_action, Name, Description).
- **Actions_Creatures** — связь M:N (id_action, id_creature).
- **Feats_4** — черта (id_feat, Name, Description).
- **Creatures_Feats** — связь M:N (id_creature, id_feat, Feat_type).
- **Attacks_7** — атака (id_attack, Attack_bonus, Damage, Description, Characteristic, id_creature, Name).
- **Damage_types_6** — тип урона (id_damage, Name).

## Дополнительные сущности

- **User** — phone number/gmail
- **Role** — user, admin
- **Catalog** — хранилище сохранённых пользователем существ (id_saved, id_user, id_creature, custom_name).
- **GenerationTables** — таблицы генерации (id_table, name, description)
- **TableEntries** — запись в таблице генерации (id_entry, id_table, range_min, range_max, id_creature).

## Требования безопасности

- Пароль хранится в захэшированном виде
- Для аутентификации используется сравнение хэшей

## Требования к генератору

- Система должна поддерживать генераторы случайных чисел с различными диапазонами значений, соответствующими определённым костям.
- Каждая таблица хранит диапазон значений и ссылки на существ

## Требования к гибридизации

- Пользователь выбирает основу и донора
- Система применяет правило, те ли параметры были выбраны
- Система проверяет соответствие размера и ПО
- Создаётся гибрид
- Пользователь задаёт имя

## Требования к экспорту

- Предусмотрена возможность экспорта в формате JSON

## Требования к сохранению и каталогу

- Зарегистрированный пользователь может сохранять сгенерированных существ и гибридов.
- Сохранённые записи привязаны к пользователю.
- Пользователь может просматривать, редактировать имя.
- Каталог существ доступен всем пользователям.
- Поиск и фильтрация: по имени, типу и ПО

## Администрирование

- Администратор может управлять всеми справочниками через админ-панель.
- Все изменения сохраняются в БД.
